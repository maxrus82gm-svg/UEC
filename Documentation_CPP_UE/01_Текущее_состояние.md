# 01_Текущее_состояние

## Подтверждённое состояние

- Проект связан с C++ и Unreal Engine.
- Репозиторий используется для работы с проектом между разными компьютерами.
- Документационная система создаётся заново в Documentation_CPP_UE/.
- Полный Unreal Engine проект может быть добавлен в репозиторий отдельно.
- Фактическая структура Unreal Engine проекта пока не проанализирована в рамках новой системы.
- Правила Git и Unreal Engine будут уточняться отдельными задачами после инвентаризации реального проекта.

## Документационный цикл

- Точка входа: Documentation_CPP_UE/00_Главная.md.
- Активная задача и последний отчёт: Documentation_CPP_UE/11_Задача_агенту.md.
- Стартовые правила: Documentation_CPP_UE/12_Старт_агента.md.
- Тематические правила: Documentation_CPP_UE/20_SplitDoc/.
- История задач: Documentation_CPP_UE/20_SplitDoc/TASK_HISTORY.md.

После TASK 001 система готова принять следующую задачу. TASK 002 пока находится только в очереди и не выполнялась.

## Что пока неизвестно

Не подтверждены состав модулей, классов, плагинов, build-процесс, политика отслеживания generated-каталогов и окончательный состав корневого .gitignore. Эти сведения нельзя выдумывать до отдельного анализа.
