## Открытые вопросы

### 2026-09-04 — Какова фактическая структура Unreal Engine проекта

**Вопрос:**  
Какие каталоги, модули, плагины и проектные файлы реально входят в рабочий проект.

**Почему важно:**  
Без инвентаризации нельзя достоверно описать архитектуру, build-процесс и правила отслеживания файлов.

**Варианты:**  
- Провести read-only инвентаризацию после добавления полного проекта в репозиторий.

**Статус:**  
Открыт; относится к будущей TASK 002.

### 2026-09-04 — Какая стратегия Git и .gitignore безопасна для проекта

**Вопрос:**  
Какие файлы являются авторскими, generated, локальными или требующими индивидуальной проверки.

**Почему важно:**  
Ошибочная классификация может привести к потере нужных файлов или к добавлению машинно-зависимых данных.

**Варианты:**  
- Сформировать стратегию только после анализа фактической структуры проекта.

**Статус:**  
Открыт; относится к будущей TASK 002.
