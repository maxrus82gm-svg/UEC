# 10_Правила_агента

Краткая карта активной агентской системы проекта.

## Активные документы

- Документация: Documentation_CPP_UE/.
- Текущая задача и последний отчёт: Documentation_CPP_UE/11_Задача_агенту.md.
- START-маршрутизатор: Documentation_CPP_UE/12_Старт_агента.md.
- Тематические правила: Documentation_CPP_UE/20_SplitDoc/.
- Проектные документы: Documentation_CPP_UE/21_Project_Docs/.
- История задач: Documentation_CPP_UE/20_SplitDoc/TASK_HISTORY.md.

## Источник правды

Все новые задачи используют только Documentation_CPP_UE как активную документацию.

Documentation_DayZ_Qwest не является источником правды проекта UEC. Это read-only донор TASK 001; его пути, правила и предметный контекст нельзя использовать как действующие в новых задачах.

Постоянное правило должно иметь один канонический документ. В других местах допускается короткая ссылка, но не копия полного текста.

## Рабочий цикл

1. Агент всегда читает Documentation_CPP_UE/11_Задача_агенту.md и Documentation_CPP_UE/12_Старт_агента.md.
2. Дополнительные SplitDoc и Project_Docs читаются только по теме текущей задачи.
3. Выполняется только TASK из активного БЛОКА 1 и только в разрешённом scope.
4. Результат записывается в БЛОК 2 и TASK_HISTORY, если задача разрешает обновление документации.
5. После успешного выполнения БЛОК 1 очищается по каноническому алгоритму раздела 5 START.
6. При BLOCKED незавершённая задача автоматически не очищается.

Подробные постоянные правила находятся в Documentation_CPP_UE/12_Старт_агента.md.
