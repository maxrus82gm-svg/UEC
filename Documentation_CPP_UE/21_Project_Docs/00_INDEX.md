Здесь в будущем размещаются документы, которые описывают фактическую структуру и поведение конкретного Unreal Engine проекта:

- подтверждённая карта каталогов и модулей;
- build и test workflow;
- архитектурные контракты;
- зависимости и плагины;
- конфигурация и эксплуатационные процедуры;
- другие сведения, проверенные по реальным файлам или runtime.

На этапе TASK 001 таких подтверждённых документов ещё нет. Файлы не создаются только ради будущей структуры.

Общие правила агента и Unreal Engine находятся в Documentation_CPP_UE/20_SplitDoc/ и не дублируются здесь.
