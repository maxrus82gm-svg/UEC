### 4. Добавлена накопительная сдача предметов

Реализована новая механика для больших квестов, где игрок не может принести все предметы за один раз.

Пример: нужно сдать 50 картошек.

Теперь можно:

1. Принести 10 картошек.
2. Нажать сдачу у NPC.
3. Эти 10 картошек удалятся из инвентаря.
4. В прогрессе игрока сохранится `10 / 50`.
5. Позже принести еще 20.
6. Прогресс станет `30 / 50`.
7. Потом принести еще 20.
8. После достижения `50 / 50` квест завершится и выдаст награду.

Механика включается в JSON отдельно для каждой цели:

```json
{
  "type": "item",
  "className": "Potato",
  "quantity": 50,
  "removeOnComplete": true,
  "useItemQuantity": false,
  "allowPartialTurnIn": true
}
```

Если `allowPartialTurnIn` не указан или равен `false`, квест работает по старой логике: все предметы нужно принести сразу.

## Как проверить в игре

1. Собрать PBO.
2. Обновить серверный JSON или удалить старый, чтобы создался новый.
3. В серверном `profiles/Silver_77_Quests/Silver_77_Quests.json` добавить цель с:

```json
"allowPartialTurnIn": true
```

4. Зайти на сервер.
5. Взять накопительный квест у NPC.
6. Принести часть предметов.
7. Нажать сдачу.
8. Проверить, что:
   - предметы удалились из инвентаря;
   - квест не завершился раньше времени;
   - в меню/журнале видно `Сдано: X / Y`;
   - после добора полного количества выдается награда.

## Важные замечания

1. Старые серверные JSON-файлы не обновятся автоматически.

2. Для уже существующих квестов нужно вручную добавить:

```json
"allowPartialTurnIn": false
```

или:

```json
"allowPartialTurnIn": true
```

Поле можно не указывать, тогда будет старое поведение.

3. Для предметов вроде картошки, рыбы, мяса, банок лучше использовать:

```json
"useItemQuantity": false
```

4. Для патронов, жидкостей и предметов с внутренним количеством можно использовать:

```json
"useItemQuantity": true
```

5. Журнал по `J` не блокирует движение специально.
