### Параметры квеста (JSON)

```json
{
  "id": "quest_id",                    // Уникальный ID
  "name": "Название квеста",
  "description": "Описание задания",
  "repeatable": true,                  // Можно повторять
  "cooldownSeconds": 3600,             // Задержка до повтора (секунды)
  "requiresPrevious": "",              // ID предыдущего квеста
  "requiredQuestIds": [],              // Все обязательные выполненные квесты
  "giveItems": [...],                  // Предметы при взятии
  "objectives": [...],                 // Цели квеста
  "rewards": [...]                     // Награды
}
```

### Параметры триггера (JSON)

```json
{
  "id": "trigger_id",                  // Уникальный ID
  "position": [X, Y, Z],               // Координаты
  "radius": 3.0,                       // Радиус зоны (метры)
  "focusHeight": 1.45,                 // Высота точки наведения
  "focusRadius": 0.5,                  // Радиус точки наведения
  "questIds": ["quest_id"],            // Список квестов
  "hintText": "[F] Текст подсказки"    // Настраиваемый текст
}
```

## Для администраторов

### Быстрый старт
1. Установи мод на сервер
2. Запусти сервер - создастся конфиг
3. Останови сервер
4. Отредактируй `profiles/Silver_77_Quests/Silver_77_Quests.json`
5. Измени координаты триггеров под свою карту
6. Запусти сервер

### Как узнать координаты
1. Зайди в игру как админ
2. Встань в нужном месте
3. Открой консоль (`) и введи: `getpos`
4. Скопируй координаты в формат `[X, Y, Z]`

### Настройка cooldown
- `0` = без задержки (можно сразу повторить)
- `3600` = 1 час
- `86400` = 24 часа
- `604800` = 7 дней

### Отладка
- Проверь логи сервера на наличие `[Silver_77_Quests]`
- Убедись что конфиг создался в `profiles/Silver_77_Quests/`
- Проверь что триггеры загрузились (в логах будет количество)
