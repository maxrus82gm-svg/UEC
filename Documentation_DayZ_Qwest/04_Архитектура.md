# 04_Архитектура

Здесь храним общую архитектуру проекта: как связаны редактор, JSON, клиент, сервер, UI и правила агента.

## Основные части проекта

### Клиентский мод

Папка:
`Silver_77_Quests_Client`

Отвечает за:
- клиентский UI;
- отображение квестов;
- клиентскую часть синхронизации;
- взаимодействие игрока с интерфейсом.

### Серверный мод

Папка:
`Silver_77_Quests_Server`

Отвечает за:
- серверную логику квестов;
- проверку условий;
- выдачу наград;
- сохранение прогресса;
- обработку действий игрока.

### Редактор квестов

Папка:
`JSON_Quvest`

Отвечает за:
- создание и редактирование JSON-квестов;
- dev-данные;
- справочники item class names.

### Документация и правила

Папка:
`Documentation_DayZ_Qwest`

Важные документы:
- `Documentation_DayZ_Qwest/11_Задача_агенту.md`
- `Documentation_DayZ_Qwest/12_Старт_агента.md`
- `Documentation_DayZ_Qwest/20_SplitDoc/GIT_REVIEW_RULES.md`
- `Documentation_DayZ_Qwest/21_Project_Docs` — проектные документы

## Принцип работы с агентом

ChatGPT выбирает минимальный набор правил и документов.

Агент читает:
- `Documentation_DayZ_Qwest/11_Задача_агенту.md`;
- `Documentation_DayZ_Qwest/12_Старт_агента.md`;
- только нужные тематические документы из `Documentation_DayZ_Qwest/20_SplitDoc`;
- нужные проектные документы из `Documentation_DayZ_Qwest/21_Project_Docs`, если они указаны в задаче.
