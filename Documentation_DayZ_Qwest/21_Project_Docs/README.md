## Быстрый старт

### Для пользователей:
1. Скопируй `@Silver_77_Quests` в папку с модами
2. Добавь в `serverDZ.cfg`: `mods = @Silver_77_Quests;`
3. Запусти сервер - готово!

### Для разработчиков:
1. Собери PBO через DayZ Tools Addon Builder (см. BUILD.md)
2. Установи как обычный мод

## Автоматическое создание конфига

При первом запуске мод создаст:
```
profiles/Silver_77_Quests/
├── Silver_77_Quests.json          (минимальный стартовый конфиг квестов)
└── players/
    └── [SteamID].json             (прогресс каждого игрока)
```

Никакой ручной настройки не требуется - мод работает сразу!

## Тестирование

1. Запусти сервер
2. Зайди в игру
3. Подойди к NPC/триггеру
4. Нажми F - откроется меню квестов
5. Возьми квест, собери предметы, сдай - получи награду!

## Настройка под свою карту

Если хочешь изменить координаты триггеров:
1. Останови сервер
2. Открой `profiles/Silver_77_Quests/Silver_77_Quests.json`
3. Измени `position` в секции `triggers`
4. Запусти сервер

Подробнее: **README_JSON_CONFIG.md**
